## 開始之前

要有：

- Windows 10／11（x64）
- Hayaku 帳號，而且管理員沒有停用「應用程式透過 MCP 操作」
- （選用）Claude Code（CLI 或桌面版）：要自動為任務計時才需要
- （選用）公司 EIP 帳號：要把 EIP 的假單自動登記到 Hayaku 才需要
- （選用）可以自己建 Slack App 的工作區：要把通知傳到 Slack 私訊才需要

## 第 1 步：下載並執行

1. 到 [Releases](https://github.com/Maddog-ku/hayaku-tool/releases/latest) 下載 **HayakuBar.exe**（單一檔案，不用另外安裝 .NET）。
2. 放到固定的資料夾（例 `D:\Tools\HayakuBar\`），雙擊執行。
3. Windows 若跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

## 第 2 步：登入 Hayaku

第一次開啟會出現設定頁，按「登入 Hayaku」，在瀏覽器授權後回到工具。用的是 Hayaku 的「已連線的應用程式」，**工具不會碰到你的密碼**，之後可以在「我的 › 已連線的應用程式」隨時撤銷。

## 第 3 步：開始計時

1. 工時會出現在通知區域左側（預設）。在上面按右鍵可以換位置、換「一排／兩排」，也可以直接左右拖曳微調。
2. 點工作列上的工時（或按 `Win+Shift+H`）打開面板，在「開始任務」輸入任務編號或關鍵字，Enter 開始。
3. （選用）設定 › 專案 ›「選擇資料夾」，加入放專案的主資料夾（例 `D:\repo`）。之後 Claude 在裡面工作時，會依對話裡的任務編號或 git 分支名稱自動計時。
4. （選用）設定 › 一般 ›「開機時自動啟動」。

更新、移除的方法見 [使用說明 › 更新與移除](docs/使用說明.md#更新與移除)。

## 為什麼用 HayakuBar？

- **工時一直看得到**：工作列上就是「今天工時／應出勤」，滑過去看今天各任務的明細與時間軸，不用開網頁算。
- **自動為主，按鈕只是備援**：依 Hayaku 班表上班恢復計時、休息暫停、**休息結束自動恢復**、下班全部停止。
- **寫程式自己會記工時**：偵測 Claude Code 的活動，依對話裡的任務編號或 git 分支自動計時；對應不到任務時當場建立。
- **不用一直開網頁**：工作台 18 頁集中處理任務、專案、測試、審核、工時、會議、筆記、團隊空間、論壇、請假與統計，附件直接預覽。
- **請假只請一次**：在公司 EIP 請的假，上班前、下班時自動登記到 Hayaku。
- **離開座位也能處理**：審核、測試結果傳到 Slack 私訊，在手機上直接核准、駁回、通過、退回。
- **請求數壓得低**：各類資料分開排程同步，詳細、檔案、測試視圖都是點了才讀。
- **工時跟網頁一致**：今天工時是所有計時段的聯集，進位方式跟 Hayaku 網頁「今天的工時」一樣。

## 快速開始

照上面的[第 1 步](#第-1-步下載並執行)到[第 3 步](#第-3-步開始計時)做完就能用。接著可以：

| 想做的事 | 去哪裡 |
|----------|--------|
| 切換正在做的任務 | 把任務釘到托盤（任務右鍵 ›「📌 釘選」），面板上按 ▶，或面板開著時按 `Alt+1`～`9` |
| 處理任務、會議、測試 | 面板底部〔工作台〕，`Ctrl+1`～`9`、`0` 切換頁面 |
| EIP 請假自動登記 | 設定 › EIP 請假 › 登入 |
| 通知傳到 Slack | 設定 › Slack，照頁面上的步驟建 App、貼金鑰 |
| 補登沒填的工時 | 面板底部〔工時紀錄〕，班表裡沒有紀錄的時段點一下帶入 |

## 功能

| 範圍 | 內容 |
|------|------|
| **工作列** | `3.5h / 8h`＋進度條＋計時中的任務數＋Claude 標記；一排或兩排、位置可選、可拖曳微調；放不下時自動讓開；未讀通知紅點；滑過看今天的明細與時間軸 |
| **彈出面板** | 今天的時間軸（班表內沒計到的空檔標紅）；計時、任務、今天、通知四頁（今天頁最上面是逾期、今天到期、等你審核、今天的會議四個數字，逾期與到期的任務直接計時、改期、標完成）；上班／下班（下班可復原） |
| **托盤** | 跟網頁的釘選托盤同一份，最多 20 個；▶ 一鍵切換任務，會議開始前 10 分鐘起 ▶ 就加入並計時 |
| **我的任務** | 全部、進行中、測試、逾期、該開始、未開始、已完成；清單、樹狀、看板、日曆、甘特圖（拖拉改預計日期）；點狀態直接改；任務詳細的概況、子任務、工時記錄、相依、附件、文件（補一段、改一段、新增文件）、異動紀錄 |
| **專案** | 任一專案的整棵任務樹、套用專案視圖、篩選；勾選多個批次改狀態與欄位、套用子任務範本；貼上清單批次新增整棵任務樹 |
| **測試** | 需修復、需測試、測試總覽三種視圖；開始修、送復驗、通過、退回；測試子狀態一次推進一批 |
| **審核** | 待我審核的變更申請直接核准、拒絕；我送出的可以撤回；新申請跳提示，在提示上就能處理 |
| **工時** | 我的工時（月曆）、工時紀錄（改起訖、移到別的任務、補登）、工作日誌（✦ Claude 整理）、工作負荷、統計（匯出 CSV） |
| **會議與提醒** | 會議建立、加入、離開、取消、釘到托盤，進行中的列出誰在會議中；提醒的快速時間照自己的上班時段算 |
| **筆記、團隊空間、論壇** | 筆記本、團隊空間頁面與資料夾（新增、編輯、移動、刪除）、論壇發文與回覆；從 Excel 貼上自動變表格 |
| **檔案預覽** | 附件、會議檔案、白板、空間檔案直接看：圖片可縮放，PDF、Word、Excel、文字檔讀文字，可以全螢幕 |
| **自動上下班** | 上班恢復上次那組任務、休息暫停、休息結束自動恢復、下班全部停止；睡眠錯過的時間點醒來補做最後一個 |
| **Claude Code** | 依手動指定 → 對話裡的任務編號 → git 分支判斷任務，沒有預設任務；持續計時不因閒置暫停；可選安裝 hooks；對應不到任務時跳提示建立 |
| **EIP 請假同步** | 上班前、下班時把 EIP 的待審與核准假單登記到 Hayaku，漏掉的日子最多補 7 天；只取消同步建立的 |
| **Slack 通知** | 審核、測試結果一律傳，其他通知只在螢幕鎖定時傳；Slack 上處理了電腦的提示跟著關 |
| **外觀** | 深色／淺色跟隨 Windows 或自選；大量動畫，尊重 Windows「顯示動畫」關閉 |

每一項的細節：[使用說明 › 功能](docs/使用說明.md#功能)。

### 連線

| 連到 | 方向 | 用途 |
|------|------|------|
| Hayaku `/mcp` | 對外 HTTPS | 所有資料與操作（JSON-RPC），OAuth 2.1＋PKCE 登入 |
| `127.0.0.1:47824` | 本機 | OAuth 登入回呼，登入時才開 |
| `127.0.0.1:47823` | 本機 | 接收 Claude Code hooks |
| 公司 EIP | 對外 HTTPS | 讀假單（只讀），有設定才連 |
| Slack | 對外 WebSocket | Socket Mode 私訊與按鈕，有設定才連，不用對外開放的網址 |

## 運作方式

```
                        MCP（JSON-RPC over HTTPS /mcp）
   Hayaku  ◄──────────────────────────────────────────►  HayakuBar（常駐，嵌在工作列）
 （已連線的應用程式，OAuth 2.1）                                │
                                                              ├──► 工作列小工具（原生 Win32，嵌進 Shell_TrayWnd）
   Claude Code ── session jsonl、hooks :47823 ──────────────►├──► 面板、工作台、提示、設定（Slint）
                                                              ├──► EIP：上班前、下班時讀假單 → 登記到 Hayaku
                                                              ├──► Slack：Socket Mode 私訊、收按鈕
                                                              └──► %APPDATA%\HayakuBar：設定、狀態、紀錄、DPAPI 加密的登入資料
```

- **資料以 Hayaku 為準**：工具本身不另外存工時，按下開始／暫停馬上送給 Hayaku，Hayaku 記下的時間就是按下的時間。
- **Claude 計時**：讀 `%USERPROFILE%\.claude\projects\` 的 session 檔，用裡面的 `cwd` 決定是哪個專案；裝了 hooks 時送出指令就馬上開始。
- **請假、放假、週末不送請求**：下班時記下接下來 30 天不用上班的日子，這些日子啟動、打開面板都不跟 Hayaku 要資料（按 ⟳ 才會）。
- **執行環境**：Rust 單一 exe，介面用 [Slint](https://slint.dev)，網路在 tokio 背景執行緒；v1.9.1 以前是 C# WPF 版（`src/`、`tests/`，已停止維護）。

## 建置與測試

需要 Rust（`stable-x86_64-pc-windows-msvc`）與 VS 2022 Build Tools（C++ 工作負載）。

| 指令 | 做什麼 |
|------|--------|
| `cargo test --workspace` | 全部單元測試（在 `rust/` 底下跑） |
| `cargo run -p hayakubar` | 跑除錯版 |
| `.\publish.ps1` | 輸出 `publish\rust\HayakuBar.exe`，建完刪掉 `rust\target`（`-KeepTarget` 保留） |
| `HayakuBar.exe --shot:頁面,…` | 把各頁畫面存成 PNG 到 `%APPDATA%\HayakuBar\shots`，檢查畫面用 |
| `HayakuBar.exe --mcp-call <工具> <參數JSON> <輸出檔>` | 診斷：用目前登入呼叫一支 MCP 工具（先關掉執行中的 HayakuBar） |
| `git push origin vX.Y.Z` | GitHub Actions 檢查版本號、跑測試、建置 exe 並發佈 Release |

`HAYAKUBAR_DATA_DIR=<資料夾>` 讓設定與紀錄改放那個資料夾，可以跟正在用的 HayakuBar 同時開。

**每次發版都要附**：`rust/Cargo.toml` 的版本號、[CHANGELOG.md](CHANGELOG.md) 的新版本條目（新增、修正、沒有跟的、已知問題），功能有變時一起更新 README 與[使用說明](docs/使用說明.md)。完整的啟動參數、發佈流程與程式結構：[開發說明](docs/開發說明.md)。

## 進行中

- **欄位待核對**：測試結果、會議紀錄人、相關任務與會議、自訂欄位、里程碑、子任務範本等回應沒有實際資料，照工具說明寬鬆解析，有資料後要回頭核對。
- **沒有實測**：任務文件的補一段、改一段、新增文件（避免改到公司文件）。
- **還沒做**：筆記本頁、團隊空間會議節點釘到托盤（還沒有實際資料可以核對格式）。
- **MCP 做不到的**：跨專案移動任務、上傳附件、托盤排序、系統與專案設定、問題回報轉任務等，畫面上放「到網頁處理」的連結。
- **舊版 C# WPF**：已停止維護，什麼時候從 repo 移除還沒決定。

## 安全

- 登入用 Hayaku 的「已連線的應用程式」（OAuth 2.1＋PKCE），工具不會碰到你的密碼；所有操作都透過 Hayaku 的 MCP 端點，跟 Claude 用同一套權限。
- Hayaku 登入資料、EIP 帳密、Slack 金鑰都用 Windows DPAPI 加密存在 `%APPDATA%\HayakuBar\`，只有同一個 Windows 帳號解得開；登出、中斷連線就刪掉。
- 工具只讀 EIP 的假單頁，不會在 EIP 上送出或修改任何東西；Slack 只私訊給設定的成員 ID，也只處理那個人按的按鈕。
- 本機只開兩個連接埠，都只聽 `127.0.0.1`。
- **不用了記得撤銷授權**：移除後到 Hayaku「我的 › 已連線的應用程式」撤銷。

細節：[使用說明 › 登入與安全](docs/使用說明.md#登入與安全)。
