# HayakuBar

嵌在 Windows 工作列裡的 [Hayaku](https://hayaku.revivalsi.com) 工時小工具。

- 工作列上隨時看到「今天工時 / 應出勤」，點一下往上彈出面板，管理計時中的任務、今天的會議與待辦、通知；
  釘選的任務放在托盤，▶ 一鍵切換正在做的任務。
- 依 Hayaku 班表**自動上下班**：上班恢復計時、休息暫停、休息結束自動恢復、下班全部停止。
- 偵測 **Claude Code** 的活動，自動為對應的任務計時；對應不到任務時還能當場建立。
- 工作台集中處理任務、待我審核、工時紀錄、工作日誌、提醒、會議、聊天、專案動態、工作負荷、請假與統計，不用一直開瀏覽器。
- 在公司 **EIP** 請假後，下班時自動登記到 Hayaku，不用請兩次假。

所有資料都以 Hayaku 為準，工具本身不另外存工時；工時的算法跟 Hayaku 網頁一致（見[工時怎麼算](#工時怎麼算)）。

## 系統需求

- Windows 10 / 11（x64）
- Hayaku 帳號，且管理員沒有停用「應用程式透過 MCP 操作」
- Claude Code 自動計時（選用）：本機有用 Claude Code（CLI 或桌面版）

## 下載與安裝

1. 到 [Releases](https://github.com/Maddog-ku/hayaku-tool/releases/latest) 下載 **HayakuBar.exe**（單一檔案，不用另外安裝 .NET）。
2. 放到固定的資料夾（例 `D:\Tools\HayakuBar\`），雙擊執行。
3. Windows 若跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

**更新**：在工作列的工時上按右鍵結束 HayakuBar，再用新的 exe 取代舊的。設定存在 `%APPDATA%\HayakuBar`，不會不見。

**移除**：結束 HayakuBar、在設定關掉「開機時自動啟動」，刪掉 exe 與 `%APPDATA%\HayakuBar` 資料夾；
有裝 Claude Code hooks 的話先在設定的「專案」頁移除。最後到 Hayaku「我的 › 已連線的應用程式」撤銷授權。

## 快速開始

1. **登入**：第一次開啟會出現設定頁，按「登入 Hayaku」，在瀏覽器授權後回到工具。
2. **看工作列**：工時會出現在通知區域左側（預設）。在上面按右鍵可以換位置、換「一排／兩排」，也可以直接左右拖曳微調。
3. **開始計時**：點工作列上的工時（或按 `Win+Shift+H`）打開面板，在「開始任務」輸入任務編號或關鍵字，Enter 開始。
4. **（選用）Claude Code 自動計時**：設定 › 專案 › 「選擇資料夾」，加入放專案的主資料夾（例 `D:\repo`）。
   之後 Claude 在裡面工作時，會依對話裡的任務編號或 git 分支名稱自動計時。
5. **（選用）開機自動啟動**：設定 › 一般 › 「開機時自動啟動」。

## 功能

### 工作列

- 顯示 `3.5h / 8h`＋進度條＋計時中的任務數＋Claude 標記，背景透明、跟著工作列的深淺色。
- 可選「一排」（較寬）或「兩排」（較窄，預設），在右鍵選單「顯示方式」或設定裡切換。
- 位置可選：最左邊、工作列圖示左側、工作列圖示右側、通知區域左側（右鍵選單或設定），也可以直接左右拖曳微調。
- 用 UI Automation 讀工作列圖示的範圍，開了很多 app 放不下時會自動移到不會蓋到圖示的位置。
- explorer 重啟後會自動重新嵌入。
- 有未讀通知時顯示紅色數字；滑鼠停在上面會跳出今天各任務的明細與時間軸。

### 彈出面板

點工作列上的工時（或按快捷鍵，預設 `Win+Shift+H`），面板從工作列往上滑出。
上方是今天的時間軸：班表時段、有計時的時段、班表內沒計到的空檔標紅，滑鼠移上去看那時在跑哪些任務。分四頁：

| 分頁 | 內容 |
| --- | --- |
| **計時** | 最上面是**托盤**（釘選的任務，見下）；計時中的任務（● 手動、✦ Claude 自動）與今天累計時間、今天做過的任務；點任務在 Hayaku 開啟；「開始任務」打字即篩選（↑↓ 選、Enter 開始，釘選的排最前面）；各專案的 Claude 狀態，可「選擇」指定 session 的任務 |
| **任務** | 我的任務（進行中、逾期…），可勾「只顯示沒有子任務的」；右鍵可停止並完成、改狀態、釘到托盤、提醒、聊天 |
| **今天** | 待我審核的筆數（點了到工作台審核）、今天的會議（快開始時可「加入並計時」）、待辦（直接勾掉）、即將到來的提醒、隨手記（可存成待辦） |
| **通知** | 最新通知，點一下在 Hayaku 開啟並標為已讀；全部標為已讀 |

底部：上班／下班（下班後可「復原」）、工時紀錄、工作台、同步狀態。

**托盤**（跟網頁的任務釘選托盤同一份）：任務右鍵或工作台任務詳細按「📌 釘選」，最多 10 個。
按 ▶ 切換到那個任務（同時暫停其他所有計時，Claude 開的也一樣，Claude 不會馬上又重開）；右鍵可以「同時計時」、取消釘選；
點名稱看詳細；面板開著時 `Alt+1`～`9` 直接切換第幾個。托盤的拖拉排序請到網頁上調。

### 工作台

從面板底部或右鍵選單開啟，`Ctrl+1`～`9`、`0` 切換頁面：

| 頁面 | 內容 |
| --- | --- |
| **我的任務** | 清單、樹狀與看板檢視；狀態篩選可以混著選狀態類別與各專案自己的狀態（處理中、待客戶回應…），專案篩選有專案圖示，有套用的篩選會亮起來；「只顯示沒有子任務的」；看板可以「不顯示完成及不處理」；依狀態排序照專案設定的狀態順序；清單可以設定欄位（顯示、順序、寬度，專案欄可以只顯示代碼），標題列直接拖寬度；樹狀可以全部收合／展開。任務詳細可以釘選、**移動**（同一個專案裡換上層或移到最上層）、勾「當作分類」，展開「子任務的工時」依子任務列出每一段；停止並完成有沒完成的子任務時，可選照專案的狀態連動或只完成這個 |
| **待我審核** | 等我審核的變更申請依專案分組，直接核准、核准並關注、拒絕（可附說明）；「我送出的」可以撤回。只有在某個專案是管理員或編輯者才會去抓待審核筆數（每 10 分鐘，或收到「有新的變更申請」通知時） |
| **我的工時** | 月曆檢視每天的工時與應出勤，標出沒填滿的日子 |
| **工時紀錄** | 任一天的計時段與時間軸，直接改起訖時間、備註、刪除；**⇆ 移到別的任務**（附復原）；列出班表裡沒有紀錄的時段，點一下帶入補登 |
| **工作日誌** | 每天各任務的工時；**✦ Claude 整理**把那天的 Claude Code 指令與自己的 git commit 依任務整理成草稿，可以先改再複製或存到隨手記，也能寫進還沒有備註的計時段（不會動已有的備註） |
| **提醒** | 新增、修改、刪除提醒，可綁任務、設重複規則 |
| **會議** | 期間內的會議，建立、加入、離開、取消；可設定加入時暫停其他計時、離開後自動恢復 |
| **聊天** | 任務或專案頻道的聊天 |
| **團隊狀況** | 團隊成員今天的班表與狀態 |
| **專案動態** | 誰新增、開始做、完成了什麼任務（跟網頁「專案動態」同一套），上方是新增／開始／完成／逾期的摘要與最活躍的人；可選專案、本週／上週／最近 30 天、進展／指派／討論／其他、只看我；任務編號點了直接打開 |
| **工作負荷** | 我一週的實際計時或預計工時（照每天容量分配），每格顯示時數／容量與做了幾個任務，合計欄顯示這週做過幾個不同任務；預計模式另列還沒填預計工時、算不進來的任務 |
| **請假** | 請假紀錄，新增與取消 |
| **EIP 請假紀錄** | 直接讀公司 EIP 的假單（待審、核准、駁回），切換上個月／下個月，標出已由同步登記到 Hayaku 的 |
| **統計** | 期間內的實際／應出勤工時、出勤天數、任務完成與逾期 |

### 提示

從工作列的工時上方滑出：

- 會議快開始（可「加入並計時」）、提醒到點（可「10 分鐘後再提醒」）、新通知。
- 下班時：可復原；工時沒滿時可補登工時、整理日誌。
- 全螢幕、簡報、Windows 勿擾時段或鎖定螢幕時先存起來，結束後再一起跳出（會議提示照跳，可在設定關掉）。

### 依班表自動上下班

班表、請假、國定假日都以 Hayaku 為準。

| 時間點 | 自動做的事 |
| --- | --- |
| 上班時間到 | 恢復上次那組任務開始計時 |
| 休息開始 | 全部暫停（Hayaku 的「依工作時間自動暫停」有開也不衝突） |
| 休息結束 | **自動恢復**休息前在跑的任務（Hayaku 本身只會發通知問你） |
| 下班時間到 | 全部停止 |

手動「上班」隨時可以按；按了「下班」當天就不再自動上班。電腦睡眠錯過的時間點，醒來後只補做最後一個。

### Claude Code 自動計時

- 只要加入放專案的**主資料夾**（例 `D:\repo`），裡面的專案會自動偵測（git repo，或 Claude 開過 session 的子資料夾），
  每個專案各自計時，可個別停用；主資料夾本身是 git repo 時，一般子資料夾不算專案。
- CLI 和桌面版的 session 都在 `%USERPROFILE%\.claude\projects\<編碼路徑>\*.jsonl`，用檔案裡的 `cwd` 決定歸屬
  （避免中文路徑撞名、名稱前綴相同的 repo 誤判），Git Bash 格式的路徑（`/d/repo/...`）也認得。
- 設定頁可「從最近的 session 加入」，直接挑 Claude 用過的資料夾。
- **任務判斷順序**：手動指定（面板 Claude 區的「選擇」，只對那個 session 有效）→ 對話裡提到的任務編號 → git 分支名稱（`feature/F2P-97-xxx`）。
  **沒有預設任務**：都偵測不到就不計時。
- Claude 有動作就開始計時，跟其他計時並行，之後**持續計時**，不會因為閒置而暫停；休息、下班或手動暫停才會停。
- 預設只在上班時間（或你有手動計時）時才自動計時。
- 選用：一鍵安裝 Claude Code hooks（寫進 repo 的 `.claude/settings.local.json`），送出指令就馬上開始計時。
- **自動建立任務**（「專案」頁逐一勾選，預設關）：Claude 開始改程式、卻對應不到任務時跳提示；
  改程式包含 Edit、Write 等工具，也包含用指令改檔（`sed -i`、python／node 腳本寫檔、重導向或 `tee` 到專案裡的檔案、`Set-Content`、`git apply`…）；
  只是問問題、規劃、跑讀取指令（`sed -n`、`grep`、`git status`）或寫到專案外（暫存資料夾）不會跳，同一個 session 只問一次。按「建立任務」開小視窗，專案自動選好（記住資料夾對應的專案與上層），
  選專案樹位置、狀態、預計起訖、**預計工時（必填）**，建好後就指定給這個 session 並馬上計時；也可以「選既有任務」。
  提示跳出時就先在背景讀好專案樹、把小視窗建好，按「建立任務」馬上出現、內容一次到位（小視窗固定在最上層，不佔工作列）；
  提示放超過 30 秒才按的，專案樹會在背景重讀，有變才更新。
  預計工時開視窗時會先請 Claude 估（在背景跑 `claude -p`，用 haiku、依任務名稱與這個 session 開頭幾句指令，約 10 秒），
  自己已經填了就不覆蓋；按「✦ 問 Claude」可以重問。這個背景呼叫不存 session、不觸發 hooks，不會被當成新工作計時。

### EIP 請假同步

在「設定 › EIP 請假」登入公司 EIP（eip.yanray.com.tw）後，在 EIP 請的假會自動登記到 Hayaku：

- **什麼時候**：有上班的日子，依班表下班時間到或按了下班時同步一次；那天電腦沒開到下班的話，下一個上班日補做
  （早上補做的不算當天的，下班時照樣再同步一次）。設定頁也可以按「立即同步」。
- **同步哪些**：EIP 上待審和核准的假單，跟「今天到下一個上班日」有重疊的整張登記（週五下班會看到週一；請好幾天的一次整段登記）。
  涵蓋當天整個上班時段的登記成整天（連續的合併成一筆），其他登記成指定時段；備註寫 EIP 單號、假別與原因。
- **不重複**：Hayaku 那段時間已經有請假（例如手動登記過）就略過。
- **取消**：EIP 駁回、抽單、被銷假整段蓋掉或改了時間時，只取消當初由同步建立的請假，手動登記的不動。
- **不上班的日子不送請求**：同步時順便記下接下來 30 天不用上班的日子（請假、放假、週末）。這些日子不同步 EIP，
  也不自動跟 Hayaku 要任何資料（啟動、定時同步、打開面板都不會；按 ⟳ 才會）。
- 有登記或取消時跳出提示，可以直接開工作台的請假頁；工作台「EIP 請假紀錄」可以看 EIP 上實際讀到的假單。

## 工時怎麼算

- **今天工時是所有計時段的聯集**：同時有好幾個任務在計時（例如手動一個、Claude 一個），重疊的時間只算一次。
  各任務自己的時間則分開算，所以「各任務加起來」可能比今天工時多。
- **顯示成小時時，先捨去不滿一分鐘的秒數**，再換算到小數點後兩位，跟 Hayaku 網頁一致：
  41 分 36 秒 → 41 分 → `0.68h`；剛好整數就不顯示小數（`8h`）。
- 計時中的任務在面板上以碼表（`0:41:42`）顯示，含秒數。
- 進行中的計時算到現在；跨日的計時只算當天的部分。

## 同步

所有資料都向 Hayaku 的 MCP 端點要，為了不一直打請求，各類資料依需要分開同步：

| 資料 | 什麼時候抓 |
| --- | --- |
| 正在計時的任務 | 每次輪詢（預設 30 秒，可在設定改） |
| 今天的計時列表 | 正在計時的有變化（開始、停止）時；不然每 5 分鐘；自己在工具裡開始／暫停／改計時後馬上 |
| 通知 | 每 2 分鐘 |
| 會議、提醒 | 每 10 分鐘（到點提示用已抓到的時間在本機判斷，不會晚） |
| 班表、專案清單、我的任務 | 每 30 分鐘 |
| 待我審核的筆數 | 某個專案是管理員或編輯者才抓：每 10 分鐘，或收到「有新的變更申請」通知時 |
| 待辦、我的任務分頁、團隊狀況、托盤 | 不在背景抓，打開面板或工作台時才抓（按 ▶ 切換、釘選後馬上更新） |

- 打開面板或工作台時會完整同步一次；20 秒內重複開關不會重抓。按 ⟳ 一定馬上同步。
- **不同步的時候**：電腦睡眠中；開了「只在上班時間自動同步」時的下班、休息、放假（有計時在跑的加班除外）。
  已經知道不用上班的日子（請假、放假、週末，見 [EIP 請假同步](#eip-請假同步)）啟動與打開面板也不同步。
  上班時間內鎖定畫面照常同步，解鎖、喚醒時會馬上同步一次。
- **失敗退避**：連續同步失敗（伺服器掛掉、網路斷）時，間隔拉長成 1 → 2 → 5 分鐘，成功一次就恢復。
- 每小時在紀錄（`logs\`）記一行 MCP 請求統計（「MCP 請求（過去 60 分鐘）：共 N 次 · …」），可以確認實際打了多少。

## 設定

在工作列的工時上按右鍵 ›「設定」開啟：

| 分頁 | 可以設定的項目 |
| --- | --- |
| **帳號** | 登入／登出 Hayaku |
| **工作列** | 顯示位置、一排／兩排、位置微調 |
| **上下班** | 依班表自動上下班開關、今天的班表 |
| **Claude Code** | 自動計時開關、只在上班時間自動計時 |
| **EIP 請假** | 登入／登出 EIP、下班時同步請假開關、立即同步與上次同步結果 |
| **專案** | 主資料夾、各專案停用、自動建立任務、安裝／移除 hooks |
| **一般** | 外觀、面板高度、快捷鍵、會議／提醒／通知提示、加入會議時暫停其他計時、全螢幕時暫緩提示、下班補登提示、開機自動啟動、只在上班時間同步、同步頻率（預設 30 秒） |

## 登入與安全

- 用 Hayaku 的「已連線的應用程式」（OAuth 2.1 + PKCE）：第一次點「登入 Hayaku」會開瀏覽器到 Hayaku 登入並授權，
  之後會出現在「我的 › 已連線的應用程式」，可以隨時撤銷。**工具不會碰到你的密碼。**
- token 用 Windows DPAPI 加密存在 `%APPDATA%\HayakuBar\auth.bin`，只有同一個 Windows 帳號解得開。
- 所有操作都透過 Hayaku 的 MCP 端點（`/mcp`），跟 Claude 用的是同一組工具、同一套權限。
  如果管理員停用了「應用程式透過 MCP 操作」，這個工具就不能用。
- **EIP 帳密**：EIP 沒有其他登入方式，只能存帳密；登入成功才會儲存，用 Windows DPAPI 加密存在 `%APPDATA%\HayakuBar\eip.bin`，
  只有同一個 Windows 帳號解得開，按「登出」就刪掉。工具只讀 EIP 的假單頁，不會在 EIP 上送出或修改任何東西。
- 本機只開兩個連接埠，都只聽本機 `127.0.0.1`：`47824` 接收 OAuth 登入回呼（登入時才開）、`47823` 接收 Claude Code hooks。

## 常見問題

**工作列上看不到工時？**
放不下時會自動移位；在系統匣找 HayakuBar 圖示按右鍵換位置。explorer 重啟後會自動重新嵌入，等幾秒即可。

**跟 Hayaku 網頁的工時不一樣？**
兩邊都是「聯集、捨去秒數、到小數點後兩位」。網頁不會自動更新，重新整理後再比；工具預設每 30 秒確認一次正在計時的任務（見[同步](#同步)），按面板底部的 ⟳ 可馬上同步。

**Claude 在工作卻沒有計時？**
確認：資料夾有加進「專案」頁、該專案沒被停用；對話或分支名稱裡有任務編號（或在面板 Claude 區按「選擇」指定）；
現在是上班時間（或關掉「只在上班時間自動計時」）。

**下班後還是自動開始計時？**
按過「下班」當天就不再自動上班；Claude 自動計時預設也只在上班時間。如果有手動計時在跑，會視為加班照常計時。

**出問題要看哪裡？**
`%APPDATA%\HayakuBar\logs\`，一天一個檔、檔名是日期時間（保留 2 個月）；設定 › 一般 ›「紀錄與設定檔」按「開啟資料夾」。

## 開發

需要 .NET 10 SDK。

```powershell
dotnet build
dotnet test
dotnet run --project src\HayakuBar
.\publish.ps1                  # 輸出 publish\HayakuBar.exe（需要 .NET 10 Desktop Runtime）
.\publish.ps1 -SelfContained   # 不需要安裝 .NET（約 70MB）
```

HayakuBar 正在執行時會鎖住 `bin\Debug` 裡的 exe，建置前先結束它（或用 `dotnet test --artifacts-path <暫存資料夾>` 把建置輸出放到別處）。

### 參與開發

`main` 有分支保護：不能直接推，要開分支、發 PR，經 repo 擁有者審核後才會合併；`v*` 版本 tag 也只有擁有者能建立。
歡迎 fork 後發 PR。

### 發佈新版本

1. 改 `src/HayakuBar/HayakuBar.csproj` 的 `<Version>`，commit 並 push。
2. 推一個同版本的 tag，GitHub Actions（`.github/workflows/release.yml`）會跑測試、打包成單一 exe（不用裝 .NET），
   並建立 Release 附上 `HayakuBar.exe` 給使用者下載：

```powershell
git tag v1.0.4
git push origin v1.0.4
```

也可以在 GitHub 的 Actions › Release › Run workflow 輸入版本號手動發佈。

## 檔案位置

| 檔案 | 用途 |
| --- | --- |
| `%APPDATA%\HayakuBar\config.json` | 設定（repo 清單、自動化開關、工作列位置） |
| `%APPDATA%\HayakuBar\state.json` | 執行狀態（要恢復的任務、今天已處理的班表時間點、Claude 開的計時、接下來不用上班的日子） |
| `%APPDATA%\HayakuBar\auth.bin` | 登入資料（DPAPI 加密） |
| `%APPDATA%\HayakuBar\eip.bin` | EIP 帳密（DPAPI 加密） |
| `%APPDATA%\HayakuBar\eip-sync.json` | EIP 請假同步：上次同步的時間與結果、由同步建立的 Hayaku 請假 |
| `%APPDATA%\HayakuBar\logs\` | 紀錄，一天一個檔，保留 2 個月 |
| `%APPDATA%\HayakuBar\shots\` | `--shot` 存的截圖 |

**紀錄**：一天一個檔，檔名是那個檔第一筆的時間（`20261029093301.log` = 2026-10-29 09:33:01 開始），
依檔名排序就是時間順序，要查哪天直接找那天開頭的檔。同一天超過 5MB 會再開一個新檔；
超過 2 個月的自動刪除，合計超過 50MB 時也從最舊的開始刪。舊版的 `log.txt`、`log.txt.1` 會依第一筆的時間改名搬進 `logs\`。

**清暫存**：啟動 3 分鐘後、之後每 30 分鐘、以及鎖定電腦時，自動刪除 3 天前的截圖（`shots\`）、2 個月前的紀錄、
寫設定時中斷留下的 `.tmp`；清掉 Claude session、專案狀態、搜尋的快取，
並把用不到的記憶體還給 Windows（面板、工作台、設定開著時不整理記憶體）；結果寫在紀錄裡（「清暫存」）。
