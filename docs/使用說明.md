## 更新與移除

**更新**：在工作列的工時上按右鍵結束 HayakuBar，再用新的 exe 取代舊的。設定存在 `%APPDATA%\HayakuBar`，不會不見。

**移除**：結束 HayakuBar、在設定關掉「開機時自動啟動」，刪掉 exe 與 `%APPDATA%\HayakuBar` 資料夾；
有裝 Claude Code hooks 的話先在設定的「專案」頁移除。最後到 Hayaku「我的 › 已連線的應用程式」撤銷授權。

## 功能

### 工作列

- 顯示 `3.5h / 8h`＋進度條＋計時中的任務數＋Claude 標記，背景透明、跟著工作列的深淺色。
- 可選「一排」（較寬）或「兩排」（較窄，預設），在右鍵選單「顯示方式」或設定裡切換。
- 位置可選：最左邊、工作列圖示左側、工作列圖示右側、通知區域左側（右鍵選單或設定），也可以直接左右拖曳微調。
- 用 UI Automation 讀工作列圖示的範圍，開了很多 app 放不下時會自動移到不會蓋到圖示的位置。
- explorer 重啟後會自動重新嵌入。
- 有未讀通知時顯示紅色數字；滑鼠停在上面會跳出今天各任務的明細與時間軸。

### 彈出面板

點工作列上的工時（或按快捷鍵，預設 `Win+Shift+H`），面板從工作列往上滑出。
上方是今天的時間軸：班表時段、有計時的時段、班表內沒計到的空檔標紅，滑鼠移上去看那時在跑哪些任務。分四頁：

| 分頁 | 內容 |
| --- | --- |
| **計時** | 最上面是**托盤**（釘選的任務與會議，見下）；計時中的任務（● 手動、✦ Claude 自動）與今天累計時間、今天做過的任務，名稱前面標上層任務（同名的子任務分得出來）；點任務在 Hayaku 開啟；「開始任務」打字即篩選（↑↓ 選、Enter 開始，釘選的排最前面）；各專案的 Claude 狀態，可「選擇」指定 session 的任務 |
| **任務** | 我的任務（進行中、測試、逾期…），可勾「只顯示沒有子任務的」；點編號是複製編號，點名稱打開任務；右鍵可停止並完成、改狀態、釘到托盤、提醒、聊天、複製連結、刪除任務 |
| **今天** | 待我審核的筆數（點了到工作台審核）、我要修的測試結果與要測的測試任務（點了到工作台的測試）、今天的會議（快開始時可「加入並計時」）、待辦（直接勾掉）、**接下來的會議**（之後 7 天內我參加的，跟今天的會議同一次讀到）、即將到來的提醒、隨手記（可存成待辦） |
| **通知** | 最新通知，點一下在工作台對應的地方處理（申請 → 待我審核、會議 → 會議詳細、任務相關 → 任務詳細、論壇、空間、頻道、補工時 → 對應頁），工作台沒有的才開網頁，並標為已讀；可封存、稍後再提醒；全部標為已讀；**討論**分頁（點了才讀）集中團隊空間評論和聊天裡 @ 你的、你負責的頁、你參與的討論串，同一段討論一列，可以分全部／空間評論／聊天，只看未解決或未讀 |

底部：上班／下班（下班後可「復原」）、工時紀錄、工作台、同步狀態。

**托盤**（跟網頁的任務釘選托盤同一份）：任務右鍵或工作台任務詳細按「📌 釘選」，最多 20 個。
按 ▶ 切換到那個任務（同時暫停其他所有計時，Claude 開的也一樣，Claude 不會馬上又重開）；右鍵可以「同時計時」、取消釘選；
點名稱看詳細；面板開著時 `Alt+1`～`9` 直接切換第幾個。托盤的拖拉排序請到網頁上調。
**會議也能釘**（工作台會議清單的 📌、會議詳細的「📌 釘到托盤」，或在會議頁按 `P`）：開會前 10 分鐘起按 ▶ 就加入會議並計時，
還沒開始的顯示開始時間；已取消、已結束的變灰、不能加入。

### 工作台

從面板底部或右鍵選單開啟，`Ctrl+1`～`9`、`0` 切換頁面：

| 頁面 | 內容 |
| --- | --- |
| **我的任務** | 分頁：**全部**（所有還沒完成的，進行中的排前面）、進行中、**測試**（指派給我的測試任務與測試結果）、逾期、該開始、未開始、**已完成**（最近完成的在最上面，可選最近 7、30、90 天或全部）。點編號是複製編號，點名稱才打開。清單、樹狀、看板、**日曆**與**甘特圖**檢視（日曆、甘特圖把任務拖到別天就改預計日期，甘特圖拖兩端改開始或結束，沒有預計日期的拖上去或拉出一段就設定，見下方說明）；狀態篩選可以混著選狀態類別與各專案自己的狀態（處理中、待客戶回應…，縮排在類別底下，有顏色點與〔全選〕〔反選〕〔全不選〕），專案篩選有專案圖示，有套用的篩選會亮起來；「只顯示沒有子任務的」；看板可以「不顯示完成及不處理」；依狀態排序照專案設定的狀態順序；清單可以設定欄位（顯示、順序、寬度，專案欄可以只顯示代碼），標題列直接拖寬度；樹狀可以全部收合／展開。清單、樹狀、看板**點狀態直接改**（清單檢視裡移到別的分頁的先留在原位、變淡標示「已移到…」，換分頁才移走）；任務按右鍵：開始／暫停計時、釘到托盤、改狀態、查看詳細、複製編號、**複製連結**、在網頁開啟、**套用子任務範本**、**刪除任務**。任務詳細可以釘選、**移動**（同一個專案裡換上層或移到最上層）、勾「當作分類」，點執行者用選人視窗改（全不選＝未指派）；展開「**概況**」看子任務進度、逾期、工時、會不會延誤、每週趨勢與各人投入；子任務清單看得到執行者、優先級、預計完成日，點一下直接改；展開「子任務的工時」依子任務列出每一段、展開「**工時記錄**」看合計、本週、本月與每個人的時數（紀錄按天分組，較早的按週、按月收起）、展開「整棵子任務樹」看子任務的子任務（最多 5 層）；停止並完成有沒完成的子任務時，可選照專案的狀態連動或只完成這個。詳細下方的**會議**（紀錄提到、內容提到、手動加入的會議，點了打開；跟任務詳細一起回來）、**相依與關聯任務**（看前置／後續、是否還擋著，新增、移除；關聯任務不擋開始、可以跨專案，能快速選同一層的任務）、**附件**（點了直接看內容；上傳到網頁）、**文件**與白板文字（每一份文件都能〔＋ 補一段〕、〔✎ 改一段〕只換某個標題底下那一段，也能〔＋ 新增文件〕；整份改寫、刪除文件、白板到網頁）、**異動紀錄**（按天分組，同一張變更申請收成一張卡，可篩選全部／留言／變更）都是展開才讀；也可以**刪除**任務（含子任務，可從網頁垃圾桶還原）。任務詳細裡 `↑` `↓` 在同一層的任務之間移動（已完成的也跳得到），可以改**類型**（一般、測試、測試結果），備註旁〔＋ 補一段〕在任務內容最後補一段 Markdown（原本的圖片、附件、表格不動）；〔＋ 子任務〕旁邊可以直接〔套用範本…〕。**測試結果**顯示分類、嚴重度、第幾輪（第 3 輪起標 🔥）、回報的人，依狀態給〔開始修〕〔送復驗〕〔通過〕〔退回〕〔不處理〕；**測試任務**顯示測試結果的進度與各狀態數量，測試結果可以用名稱或編號搜尋、依狀態篩選，〔加入測試結果〕（`R`） |
| **專案** | 任一專案的全部任務（不只指派給我的）樹狀顯示，狀態、執行者、預計結束（逾期標紅），點編號複製、點名稱看詳細；跟網頁一樣不列測試結果，測試任務後面標全部、通過、修復中、測試中的數量；可套用專案存好的視圖（條件能在本機套用就不多打請求）、篩選、依類型篩選、不顯示完成及不處理、只看我的、只顯示沒有子任務的、**只顯示已逾期**；勾選多個一次改狀態、優先級或類型，〔更多欄位…〕改預計日期（設成同一天或前後移幾個工作日）、預估工時、里程碑、自訂欄位，或〔套用範本…〕把子任務範本套到勾選的任務底下（先〔預覽〕會建哪些、日期，可略過已經有子任務的）；〔＋ 批次新增〕貼上清單一次建立多個任務或整棵任務樹（縮排是子任務，最多 100 個，全部成功或全部不建）；任務按右鍵可以計時、改狀態、刪除… |
| **測試** | 網頁的三種測試視圖：**需修復**（工程師看自己要修的：開始修時可以順手填預估工時、送復驗，直接改期限與預估工時）、**需測試**（QA 看要驗的：通過、退回填說明；要測的測試任務可以加入測試結果）、**測試總覽**（未結案、待復驗、平均輪數等數字、嚴重度分布、各測試任務的進度——名稱下面一行是**上層任務**，看得出在測哪個功能，點了前往——、逾時清單）；可選專案、只看跟我有關的、搜尋、依嚴重度篩選、依測試任務／嚴重度／執行者／專案分組，段落與分組點標題可以收合。專案有**測試子狀態**（例 待更新測試機、待上正式機）時：修好了按〔修好了，待更新〕先到下一個子狀態，列表上方有〔已更新到測試機〕〔已更新到正式機〕一次推進一批（可以填版本號當更新說明），QA 通過後先到待上正式機、上了正式機才算完成（內建的修復中、待復驗固定是每段第一列，不用自己建同名的狀態）；測試總覽列出各子狀態的筆數。收到測試結果的新通知時自動重讀 |
| **待我審核** | 等我審核的變更申請依專案分組，直接核准、核准並關注、拒絕（可附說明）；「我送出的」可以撤回。只有在某個專案是管理員或編輯者才會去抓待審核筆數（每 10 分鐘，或收到「有新的變更申請」通知時） |
| **我的工時** | 月曆檢視每天的工時與應出勤，標出沒填滿的日子 |
| **工時紀錄** | 任一天的計時段與時間軸，直接改起訖時間、備註、刪除；日期兩邊切前一天、後一天，**點日期從日曆選**；**⇆ 移到別的任務**（選好任務直接移過去，附復原）；列出班表裡沒有紀錄的時段，點一下帶入補登 |
| **工作日誌** | 每天各任務的工時；**✦ Claude 整理**把那天的 Claude Code 指令與自己的 git commit 依任務整理成草稿，可以先改再複製或存到隨手記，也能寫進還沒有備註的計時段（不會動已有的備註） |
| **提醒** | 新增、修改、刪除提醒，可綁任務或會議、設重複規則；**快速時間照自己的上班時段即時算**：5 分鐘、10 分鐘、1 小時後、午休後、今天下班前（下班前幾分鐘可在設定調整，預設 15）、明天上班、下個工作日上午與下午；「綁在」直接列出最近填過、指派給我的任務和近期會議；綁任務時可以照任務的預計開始／結束前後幾天提醒（任務改日期提醒跟著動），也可以提醒任務的所有執行者 |
| **會議** | 期間內的會議，建立、加入、離開、取消、釘到托盤（`P`）；今天的會議排在「現在」線上下，進行中的放大並列出誰在會議中、還沒加入、請假，開過的收成「今天已結束」一區；可設定加入時暫停其他計時、離開後自動恢復。點一場看詳細（參加者與各自的工時、**紀錄人**（資訊列和參加者清單都會標出來；指定紀錄人要到網頁）、重複規則、綁到的團隊空間、**相關任務**——狀態、執行者、預計日期，點了打開任務），可修改名稱、時間、地點、參加者、會議紀錄（重複會議可選只改這場或這場以後）；會議紀錄、紀錄更新歷程（誰改了什麼）、檔案、白板展開才讀，檔案點了直接看內容，白板可以看圖 |
| **聊天** | 任務或專案頻道的聊天 |
| **筆記** | 我的筆記本：清單與搜尋（頁名與內容），看內容與待辦，新增一頁、在一頁最後附加內容 |
| **團隊空間** | 選空間看頁面樹、搜尋、看頁面內容，新增子頁、附加內容、**編輯**（改頁名、整頁換內容）、**移動**到別的上層、**上移／下移**（同一層裡換順序）、**刪除**（連子頁，30 天內可在網頁還原）；專案裡開的空間標專案代碼，專案封存了的唯讀；**資料夾**（Hayaku 1.4 起取代檔案庫，舊的檔案庫自動變成同名資料夾）列出子資料夾、文件、白板與檔案（修改時間到秒，滑過看得到星期），可以在裡面新增文件和子資料夾，檔案點兩下直接看內容，也可以下載原檔；搜尋也找得到檔名，點了打開所在的資料夾和預覽（上傳、打包 zip 下載到網頁）；**綁進空間的會議**（會議資料夾、場次、那場的紀錄與白板）也在頁面樹上，紀錄跟會議頁同一份，標題右邊的〔打開會議〕到會議頁改；左邊頁面樹和右邊中間的**分隔線可以拖動調寬**，會記住調的寬度，雙擊分隔線回到預設 |
| **論壇** | 選專案與論壇看貼文（可只看未解決）、貼文與回覆，可以回覆、發新文 |
| **團隊狀況** | 團隊成員今天的班表與狀態；正在計時的任務用專案顏色，標上層任務名稱（打開這頁才補讀看得到的任務，同一個任務只讀一次） |
| **專案動態** | 誰新增、開始做、完成了什麼任務（跟網頁「專案動態」同一套），上方是新增／開始／完成／逾期的摘要與最活躍的人；可選專案、本週／上週／最近 30 天、進展／指派／討論／其他、只看我；任務編號點了直接打開 |
| **工作負荷** | 我一週的實際計時或預計工時（照每天容量分配，容量扣請假、出差，參加的會議也算進去），每格顯示時數／容量與做了幾個任務，合計欄顯示這週做過幾個不同任務；預計模式另列還沒填預計工時、算不進來的任務 |
| **請假** | 右上切換兩個分頁。**Hayaku**：請假與**出差**紀錄（所有人），新增與取消；出差照常算上班時數，登記時選一個任務，出差時段過了 Hayaku 自動把工時寫到那個任務。**EIP 假單**：直接讀公司 EIP 上自己的假單（待審、核准、駁回），切換上個月／下個月，標出已由同步登記到 Hayaku 的；只能看，切過去才讀 |
| **統計** | 依專案或依人；本週、上週、本月、上月、最近 30 天、今年、自訂期間；實際與預計工時、完成任務、逾期，各專案（或各人）工時長條與比例、明細表；可以**匯出 CSV**（Excel 打得開中文） |

**選任務**（移動工時、出差、Claude 選既有任務…都用同一個視窗）：每列看得到所屬專案和上層、可以搜尋；沒打字時先列今天計時過的「最近填過」、再列指派給我的；已完成、已取消、當作分類的任務灰掉並寫原因（只用已經讀過的專案資料判斷，沒讀過的不會標）。

**選人**（任務執行者、子任務執行者、會議參加者、測試結果要誰修）：名字、帳號都能搜，字首圓頭像；多選時〔本專案成員〕一次加入、〔全不選〕。

筆記、團隊空間、論壇、會議紀錄的內容輸入框：**從 Excel（或 Google 試算表）複製貼上會變成表格**，〔▦ 表格〕插入空白表格（送出的是 Markdown 表格）。

**直接看檔案內容**：附件、會議檔案、白板、空間檔案、問題回報截圖點了開預覽視窗，圖片看圖（滾輪縮放、拖曳移動、雙擊切換「符合視窗」與 100%，下方有縮放按鈕；可另存），PDF、Word、Excel、CSV、文字檔讀文字（很長的按「繼續讀」）；下方〔全螢幕〕或 Ctrl＋Shift＋F 切換全螢幕，全螢幕時按 Esc 先回到視窗。
同一個檔案讀過就用快取；Hayaku 限制每人 10 分鐘讀 30 次（跟 Claude 共用），工具自己最多用 24 次，超過會請你等一下。每次讀 Hayaku 都會留稽核紀錄，系統管理員可以在系統設定的 MCP 關掉。

**問題回報**（有「問題回報」權限才會收到通知）：點通知開獨立視窗看全文、處理說明、環境、處理紀錄與截圖；轉任務、改狀態請到網頁。

### 提示

從工作列的工時上方滑出：

- 會議快開始（可「加入並計時」）、提醒到點（可「10 分鐘後再提醒」）、新通知。
- **有新的申請等我審核**（某個專案是管理員或編輯者）：寫出申請人、任務、改了什麼與理由，可以直接「核准」「駁回」或「查看」（到工作台的待我審核）。
  駁回會開小視窗，可填給申請人的說明；新增任務的申請駁回會刪掉那個任務（連同已記的工時），先講清楚再送出。
  處理完跳提示告知結果，並把對應的「有新的變更申請」通知標為已讀（這類通知不會另外再跳一則）。
  跟著通知輪詢約 2 分鐘內會跳，不多打請求；一次超過 3 筆合成一則。開程式之前就在等的申請不跳，到工作台看。
- **測試結果**：被退回時可以直接〔開始修〕（開小視窗填預估工時，預設一起開始計時）；修好送復驗後，回報的人可以直接〔通過〕〔退回〕（填說明）。跟著通知輪詢，不多打請求。
- 下班時：可復原；工時沒滿時可補登工時、整理日誌。
- 全螢幕、簡報、Windows 勿擾時段或鎖定螢幕時先存起來，結束後再一起跳出（會議提示照跳，可在設定關掉）。

### 依班表自動上下班

班表、請假、國定假日都以 Hayaku 為準。

| 時間點 | 自動做的事 |
| --- | --- |
| 上班時間到 | 恢復上次那組任務開始計時 |
| 休息開始 | 全部暫停（Hayaku 的「依工作時間自動暫停」有開也不衝突） |
| 休息結束 | **自動恢復**休息前在跑的任務（Hayaku 本身只會發通知問你） |
| 下班時間到 | 全部停止 |

手動「上班」隨時可以按；按了「下班」當天就不再自動上班。電腦睡眠錯過的時間點，醒來後只補做最後一個。

### Claude Code 自動計時

- 只要加入放專案的**主資料夾**（例 `D:\repo`），裡面的專案會自動偵測（git repo，或 Claude 開過 session 的子資料夾），
  每個專案各自計時，可個別停用；主資料夾本身是 git repo 時，一般子資料夾不算專案。
- CLI 和桌面版的 session 都在 `%USERPROFILE%\.claude\projects\<編碼路徑>\*.jsonl`，用檔案裡的 `cwd` 決定歸屬
  （避免中文路徑撞名、名稱前綴相同的 repo 誤判），Git Bash 格式的路徑（`/d/repo/...`）也認得。
- 設定頁可「從最近的 session 加入」，直接挑 Claude 用過的資料夾。
- **任務判斷順序**：手動指定（面板 Claude 區的「選擇」，只對那個 session 有效）→ 對話裡提到的任務編號 → git 分支名稱（`feature/F2P-97-xxx`）。
  **沒有預設任務**：都偵測不到就不計時。
- Claude 有動作就開始計時，跟其他計時並行，之後**持續計時**，不會因為閒置而暫停；休息、下班或手動暫停才會停。
- 預設只在上班時間（或你有手動計時）時才自動計時。
- 選用：一鍵安裝 Claude Code hooks（寫進 repo 的 `.claude/settings.local.json`），送出指令就馬上開始計時。
- **自動建立任務**（「專案」頁逐一勾選，預設關）：Claude 開始改程式、卻對應不到任務時跳提示；
  改程式包含 Edit、Write 等工具，也包含用指令改檔（`sed -i`、python／node 腳本寫檔、重導向或 `tee` 到專案裡的檔案、`Set-Content`、`git apply`…）；
  只是問問題、規劃、跑讀取指令（`sed -n`、`grep`、`git status`）或寫到專案外（暫存資料夾）不會跳，同一個 session 只問一次。
  沒理會的提示預設 5 分鐘後自動收起（設定 › 一般可改成 15 秒～30 分鐘、自訂秒數或不自動收起），收起後可以在面板 Claude 區按「選擇」補指定。按「建立任務」開小視窗，專案自動選好（記住資料夾對應的專案與上層），
  選專案樹位置、狀態、預計起訖、**預計工時（必填）**，建好後就指定給這個 session 並馬上計時；也可以「選既有任務」。
  提示跳出時就先在背景讀好專案樹、把小視窗建好，按「建立任務」馬上出現、內容一次到位（小視窗固定在最上層，不佔工作列）；
  提示放超過 30 秒才按的，專案樹會在背景重讀，有變才更新。
  預計工時開視窗時會先請 Claude 估（在背景跑 `claude -p`，用 haiku、依任務名稱與這個 session 開頭幾句指令，約 10 秒），
  自己已經填了就不覆蓋；按「✦ 問 Claude」可以重問。這個背景呼叫不存 session、不觸發 hooks，不會被當成新工作計時。

### EIP 請假同步

在「設定 › EIP 請假」登入公司 EIP（eip.yanray.com.tw）後，在 EIP 請的假會自動登記到 Hayaku：

- **什麼時候**：有上班的日子同步兩次——**上班前**（第一段上班前 15 分鐘起；開機時已經過了上班時間就馬上做），
  和**下班時**（依班表下班時間到或按了下班）。設定頁也可以按「立即同步」。
- **上班前那次做完才自動上班**：早上臨時在 EIP 請了整天假，同步登記後重抓班表，今天就不會自動上班；
  請了上午的假就等下午那段才上班。EIP 連不上的話照常上班，30 分鐘後再試。
- **同步哪些**：EIP 上待審和核准的假單，跟「今天到下一個上班日」有重疊的整張登記（週五下班會看到週一；請好幾天的一次整段登記）。
  已經開始、已經過去的也登記（例如早上請的假，進公司才同步）。
- **補登漏掉的日子**：上次自動同步之後漏掉的日子（例如臨時請整天假、那天電腦沒開）下次一起補登，最多往回 7 天。
  時間已經過去的假單 Hayaku 不收的話，不會整次重試，提示與設定頁會寫「登記失敗，請到網頁登記」。
  涵蓋當天整個上班時段的登記成整天（連續的合併成一筆），其他登記成指定時段；備註寫 EIP 單號、假別與原因。
- **不重複**：Hayaku 那段時間已經有請假（例如手動登記過）就略過。
- **取消**：EIP 駁回、抽單、被銷假整段蓋掉或改了時間時，只取消當初由同步建立的請假，手動登記的不動。
- **不上班的日子不送請求**：同步時順便記下接下來 30 天不用上班的日子（請假、放假、週末）。這些日子不同步 EIP，
  也不自動跟 Hayaku 要任何資料（啟動、定時同步、打開面板都不會；按 ⟳ 才會）。
- 有登記或取消時跳出提示，可以直接開工作台的請假頁；工作台請假頁的「EIP 假單」分頁可以看 EIP 上實際讀到的假單。

### Slack 通知

在「設定 › Slack」連好自己的 Slack App 後，通知會私訊到 Slack（左邊「應用程式」的 HayakuBar），可以直接在 Slack 上處理：

- **建立 App**：按「複製 App 設定」→「開啟 Slack App 管理頁」→ Create New App → From a manifest → 選工作區 → 貼上 → Create。
  權限只有私訊（`chat:write`、`im:write`），已經開好 Socket Mode 與按鈕互動。再到 Install App 安裝（工作區要管理員核准的話會先送出申請），
  把 Bot User OAuth Token（`xoxb-`）、App-Level Token（`xapp-`，Basic Information 產生，加 `connections:write`）和自己的成員 ID 貼到設定頁，
  按「連線並送測試訊息」，兩組金鑰都對、測試訊息送到了才會儲存。
- **傳什麼**：要動手處理的一律傳——待我審核（✓ 核准、核准並關注、✕ 駁回）、測試結果待復驗（✓ 通過、↩ 退回）、
  測試結果被退回（▶ 開始修並計時）；其他通知只在**螢幕鎖定**時傳（標為已讀、封存），一次超過 3 則合成一則（全部標為已讀）。
  每則都有「開啟」直接開網頁。電腦上的提示照樣跳。
- **要填原因的**：駁回（說明可不填；駁回新增任務的申請會先警告會刪掉那個任務）、退回（一定要填）會在 Slack 跳出表單。
- **兩邊會跟著變**：在 Slack 處理了，訊息的按鈕換成結果（例「✓ 已核准（10:32，從 Slack）」），電腦上那則提示也會關掉；
  在 HayakuBar 或網頁先處理了，Slack 那則訊息改成「已在 HayakuBar 或網頁處理」、按鈕拿掉。失敗時按鈕留著，下面寫原因。
- **不用對外開放的網址**：HayakuBar 用 Slack 的 Socket Mode 主動連到 Slack（斷線自動重連）。所以電腦要開著、HayakuBar 要在跑，
  Slack 上按的按鈕才會有反應；也只用同步已經抓到的通知判斷，不會多跟 Hayaku 要資料。
- 傳過的訊息記 7 天，重開程式後按鈕也能用；同一組 App-Level Token 不要同時給兩台電腦的 HayakuBar 用（按鈕會被分給不同台）。

## 工時怎麼算

- **今天工時是所有計時段的聯集**：同時有好幾個任務在計時（例如手動一個、Claude 一個），重疊的時間只算一次。
  各任務自己的時間則分開算，所以「各任務加起來」可能比今天工時多。
- **有沒有填滿應出勤**：已填和應出勤都算到分再比，差不到半分鐘就算填滿（跟 Hayaku 一樣）；下班提示、月曆、工時紀錄、面板都用同一套，不會出現「還差 0 分」卻照樣提醒。
- **顯示成小時時，跟 Hayaku 網頁「今天的工時」一致**：今天的總工時把聯集的秒數**四捨五入到分**，各任務的時數**捨去**不滿一分鐘的秒數，
  再換算到小數點後兩位：總工時 8 分 56 秒 → 9 分 → `0.15h`；任務 41 分 36 秒 → 41 分 → `0.68h`；剛好整數就不顯示小數（`8h`）。
- Hayaku 記下的開始、結束時間是整分鐘；按下開始／暫停的請求馬上送出（不等背景同步），Hayaku 記下的時間才會跟按下的時間一致。剛暫停的計時直接顯示 Hayaku 記下的整分結束時間，不會跑到整分才停；同一分鐘內又按開始，馬上接著跑，不用等到整分。
- 計時中的任務在面板上以碼表（`0:41:42`）顯示，含秒數。
- 進行中的計時算到現在；跨日的計時只算當天的部分。

## 同步

所有資料都向 Hayaku 的 MCP 端點要，為了不一直打請求，各類資料依需要分開同步：

| 資料 | 什麼時候抓 |
| --- | --- |
| 正在計時的任務 | 每次輪詢（預設 30 秒，可在設定改）；面板、工作台都沒開、Claude 也沒在動時放慢成兩倍 |
| 今天的計時列表 | 正在計時的有變化（開始、停止）時；不然每 5 分鐘；自己在工具裡開始／暫停／改計時後馬上 |
| 通知 | 每 2 分鐘 |
| 會議、提醒 | 每 10 分鐘（到點提示用已抓到的時間在本機判斷，不會晚） |
| 班表、專案清單 | 每 30 分鐘 |
| 待我審核的筆數 | 某個專案是管理員或編輯者才抓：每 10 分鐘，或收到「有新的變更申請」通知時 |
| 我的任務 | 一個請求讀全部未完成的，進行中、測試、未開始、逾期、該開始五個分頁在本機分（跟網頁同一套規則）；背景每 30 分鐘，打開面板或工作台時更新。已完成分頁切過去才讀（一個請求） |
| 測試視圖、檔案內容、問題回報 | 打開那一頁、點了才讀；測試頁開著時收到測試結果的新通知才重讀 |
| 待辦、團隊狀況、托盤 | 不在背景抓，打開面板或工作台時才抓（按 ▶ 切換、釘選後馬上更新） |

- 打開面板或工作台時會完整同步一次；1 分鐘內重複開關不會重抓。按 ⟳ 一定馬上同步。
- 這一小時送了多少請求、各是哪些：設定 → 一般 →「同步頻率」底下；每小時也會寫一行到紀錄。
- **不同步的時候**：電腦睡眠中；開了「只在上班時間自動同步」時的下班、休息、放假（有計時在跑的加班除外）。
  已經知道不用上班的日子（請假、放假、週末，見 [EIP 請假同步](#eip-請假同步)）啟動與打開面板也不同步。
  上班時間內鎖定畫面照常同步，解鎖、喚醒時會馬上同步一次。
- **失敗退避**：連續同步失敗（伺服器掛掉、網路斷）時，間隔拉長成 1 → 2 → 5 分鐘，成功一次就恢復。
- 每小時在紀錄（`logs\`）記一行 MCP 請求統計（「MCP 請求（過去 60 分鐘）：共 N 次 · …」），可以確認實際打了多少。

## 登入與安全

- 用 Hayaku 的「已連線的應用程式」（OAuth 2.1 + PKCE）：第一次點「登入 Hayaku」會開瀏覽器到 Hayaku 登入並授權，
  之後會出現在「我的 › 已連線的應用程式」，可以隨時撤銷。**工具不會碰到你的密碼。**
- token 用 Windows DPAPI 加密存在 `%APPDATA%\HayakuBar\auth.bin`，只有同一個 Windows 帳號解得開。
- 所有操作都透過 Hayaku 的 MCP 端點（`/mcp`），跟 Claude 用的是同一組工具、同一套權限。
  如果管理員停用了「應用程式透過 MCP 操作」，這個工具就不能用。
- **EIP 帳密**：EIP 沒有其他登入方式，只能存帳密；登入成功才會儲存，用 Windows DPAPI 加密存在 `%APPDATA%\HayakuBar\eip.bin`，
  只有同一個 Windows 帳號解得開，按「登出」就刪掉。工具只讀 EIP 的假單頁，不會在 EIP 上送出或修改任何東西。
- **Slack 金鑰**：自己建的 Slack App 的 Bot Token 與 App-Level Token，用 Windows DPAPI 加密存在 `%APPDATA%\HayakuBar\slack.bin`，
  按「中斷連線」就刪掉。只私訊給設定的成員 ID，也只處理那個人按的按鈕。
- 本機只開兩個連接埠，都只聽本機 `127.0.0.1`：`47824` 接收 OAuth 登入回呼（登入時才開）、`47823` 接收 Claude Code hooks。

## 常見問題

**工作列上看不到工時？**
放不下時會自動移位；在系統匣找 HayakuBar 圖示按右鍵換位置。explorer 重啟後會自動重新嵌入，等幾秒即可。

**跟 Hayaku 網頁的工時不一樣？**
兩邊都是「聯集、總工時四捨五入到分（各任務捨去秒數）、到小數點後兩位」。網頁不會自動更新，重新整理後再比；工具預設每 30 秒確認一次正在計時的任務（見[同步](#同步)），按面板底部的 ⟳ 可馬上同步。

**Claude 在工作卻沒有計時？**
確認：資料夾有加進「專案」頁、該專案沒被停用；對話或分支名稱裡有任務編號（或在面板 Claude 區按「選擇」指定）；
現在是上班時間（或關掉「只在上班時間自動計時」）。

**下班後還是自動開始計時？**
按過「下班」當天就不再自動上班；Claude 自動計時預設也只在上班時間。如果有手動計時在跑，會視為加班照常計時。

**出問題要看哪裡？**
`%APPDATA%\HayakuBar\logs\`，一天一個檔、檔名是日期時間（保留 2 個月）；設定 › 一般 ›「紀錄與設定檔」按「開啟資料夾」。

## 檔案位置

| 檔案 | 用途 |
| --- | --- |
| `%APPDATA%\HayakuBar\config.json` | 設定（repo 清單、自動化開關、工作列位置） |
| `%APPDATA%\HayakuBar\state.json` | 執行狀態（要恢復的任務、今天已處理的班表時間點、Claude 開的計時、接下來不用上班的日子） |
| `%APPDATA%\HayakuBar\auth.bin` | 登入資料（DPAPI 加密） |
| `%APPDATA%\HayakuBar\eip.bin` | EIP 帳密（DPAPI 加密） |
| `%APPDATA%\HayakuBar\eip-sync.json` | EIP 請假同步：上次同步的時間與結果、由同步建立的 Hayaku 請假 |
| `%APPDATA%\HayakuBar\slack.bin` | Slack App 金鑰與成員 ID（DPAPI 加密） |
| `%APPDATA%\HayakuBar\slack.json` | 傳到 Slack 的訊息對應哪個通知或申請、處理了沒（保留 7 天） |
| `%APPDATA%\HayakuBar\logs\` | 紀錄，一天一個檔，保留 2 個月 |
| `%APPDATA%\HayakuBar\shots\` | `--shot` 存的截圖 |

**紀錄**：一天一個檔，檔名是那個檔第一筆的時間（`20261029093301.log` = 2026-10-29 09:33:01 開始），
依檔名排序就是時間順序，要查哪天直接找那天開頭的檔。同一天超過 5MB 會再開一個新檔；
超過 2 個月的自動刪除，合計超過 50MB 時也從最舊的開始刪。舊版的 `log.txt`、`log.txt.1` 會依第一筆的時間改名搬進 `logs\`。

**清暫存**：啟動 3 分鐘後、之後每 30 分鐘、以及鎖定電腦時，自動刪除 3 天前的截圖（`shots\`）、2 個月前的紀錄、
寫設定時中斷留下的 `.tmp`；清掉 Claude session、專案狀態、搜尋的快取，
並把用不到的記憶體還給 Windows（面板、工作台、設定開著時不整理記憶體）；結果寫在紀錄裡（「清暫存」）。
